# 微信群 AI 助手（实验版）

Windows 微信 4.x 的非官方群聊 AI 助手。它只处理配置文件中指定群、指定成员对机器人的**真实 @**，用 DeepSeek 回答，并可在当前群保存带来源的记忆和个人回复偏好。

这是供学习和二次开发的源码，**不是开箱即用的微信插件**。目前实测的是私人 Windows 虚拟机里的 v13 原型；这个公开目录为保护真实群资料改写了配置与依赖导入方式，尚未在真实微信账号上重新验证。微信升级或上游库改变后可能无法工作。

## 功能

- 核对登录账号、群 ID、群名和成员清单；成员变化时停止处理该群。
- 只识别微信消息元数据里的真实 @，忽略手打的 `@名字` 和启动前的旧消息。
- 回答时筛选当前群最近 10 条消息及最多 10 条相关记忆，标注当前提问者。
- `记住：内容` 将信息保存 30 天，仅在当前群共享，并记录提供者与时间；`我的记忆`、`群记忆`、`更新记忆 编号：内容`、`删除记忆 编号` 用于查看和管理。
- `设置我的偏好：内容`、`清除我的偏好` 分别设置和清除每人每群一条回复风格；`如何使用你` 显示命令说明。
- 明显的密码、验证码、API 密钥等凭据会在本地拦截；其余保存内容交给模型进一步判断。自动识别可能漏判，**不要在群里发送真实凭据**。

## 环境与安装

需要 Windows、Python 3.12、Git、可登录的微信 4.x 客户端和自己的 DeepSeek API 密钥。读取消息依赖第三方 [`wechatauto-replica`](https://github.com/fanyuantaier/wechatauto-replica)；本项目将其锁定在本地检查过的提交 `d322c4a9b1124228820bab363e5676016f188fc6`，不包含上游源码或微信安装包。上游使用 Apache-2.0 许可证；本项目自身代码见 `LICENSE`。

在 PowerShell 中进入本项目目录后：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
Copy-Item .\config\groups.example.json .\config\groups.json
```

编辑 `config\groups.json`，填入**自己的**群 ID、群名、当前人数、完整成员 ID 清单、管理员 ID 和机器人微信 ID。示例里的 ID 都是虚构值，不能直接运行。配置文件被 `.gitignore` 排除，勿提交到 GitHub。读取这些 ID 需要自行理解上游库的数据接口；当前版本没有自动配置向导。

先用自己的测试号和知情成员的小群验证。保持微信已登录、Windows 未锁屏，在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m wechat_group_ai.bot --ai
```

程序提示时，在终端输入 DeepSeek 密钥，输入不会显示；看到 `MEMORY_READY` 后才开始监听新消息。不要把密钥写进代码、配置或聊天。按 `Ctrl+C` 停止；关掉程序窗口或虚拟机也会停止。程序不会开机自启。

## 群里怎样使用

在微信群输入 `@`，**从弹出的成员列表点选机器人**，在自动生成的 @ 后输入空格和正文。例如：`@机器人 记住：周五晚上讨论机械臂`。直接手打 `@机器人` 不算真正的 @。回复仅在预先配置的群里发送，群中所有成员可见。

普通群信息、个人说法和玩笑可以保存，但它们是“某群员在某时说过的话”，不是已核实的事实。个人偏好只影响机器人回复设置者时的风格。每条内容最多 240 字；群记忆 30 天到期，偏好直到本人清除。群中关于他人的信息也可能被保存并供本群查询，请只在所有参与者了解该行为的群里使用。

## 数据、风险与已知问题

- `config/groups.json` 存放真实账号与群标识，`data/` 存放记忆数据库；二者都被 Git 忽略。上游库可能在本机另存微信数据库解密缓存，请参阅上游文档管理这些文件。
- 相关群聊和记忆会发送给 DeepSeek 处理；不要在涉及不愿分享给模型的信息的群里使用。群员文字作为数据交给模型，过滤与凭据识别不能保证零误判。
- 这不是微信官方接口。个人账号可能受客户端兼容性、账号规则和版本更新影响。原型曾遇到微信数据库 WAL 合并警告、漏读最近消息、自动打开群界面失败，以及记忆已写入但回复发送失败的问题。
- 公开版没有经过微信实测；也没有验证安装流程适用于另一台电脑。不要据此认为它已可稳定运行或适合无人值守。
